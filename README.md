## Overview
This project builds an interactive revenue analytics dashboard for e-commerce using the Kaggle Online Retail dataset. It integrates sales tracking, customer cohort analysis, and revenue trends with features like ribbon charts, AI-powered forecasting, and drill-through reports for top products.

Key Features:
- Sales and Revenue Trends: Visualize daily/ monthly sales with ribbon charts.
- Customer Cohorts: Analyze retention and lifetime value by acquisition month.
- Profit Trends: Track revenue as a proxy for profit (extendable with cost data).
- AI Forecasting: Predictive visuals for future sales.
- Drill-Through: Dive into top products, countries, or customers.
- Data Sources: Simulates QuickBooks integration via CSV/Excel import.

Tech Stack : Excel (Power Query), SQL, Python (Pandas, Prophet for forecasting), Power BI.
